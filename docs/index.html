Install

One command installs everything for your platform.

iOS

iPhone app - available on the App Store (free, open source)

  1. Download from the App Store
  2. Create a Tailscale OAuth client with Devices: Read
  3. Paste Client ID and Secret into the app

macOS

Menubar app + CLI - macOS 13+

curl -sSL https://raw.githubusercontent.com/zeulewan/web-finder/main/install.sh | bash
  1. Clones repo to ~/.web-finder
  2. Downloads & installs WebFinder.app
  3. Adds web-finder to PATH

Ubuntu / Linux

CLI only - requires Node.js (auto-installed if missing)

curl -sSL https://raw.githubusercontent.com/zeulewan/web-finder/main/install.sh | bash
  1. Installs Node.js LTS if needed
  2. Clones repo to ~/.web-finder
  3. Adds web-finder to PATH

What it scans

Automatically detects web interfaces across common ports.

💻

Local machine

Scans 127.0.0.1 for open ports and fetches page titles to identify services.

🌐

Tailscale peers

Reads tailscale status and scans every online peer in parallel.

📦

NAS & storage

Synology DSM, TrueNAS, and other web UIs on ports 80, 443, 5000, 5001.

🧪

Dev servers

React, Next.js, Vite, and any server on ports 3000-3001, 4000-4001, 8000-8005.

🤖

AI / ML tools

Jupyter (8888), Gradio (7860), TensorBoard (6006), and Prometheus (9090).

📋

Agent-friendly CLI

JSON output mode lets AI agents and scripts query your network programmatically.

CLI usage

Works great standalone or piped into scripts and AI agents.

web-finder Full scan - local + all Tailscale peers
web-finder --local Scan local machine only
web-finder --tailscale Scan Tailscale peers only
web-finder --all Include non-web ports (AirPlay, SSH, etc.)
web-finder --json Machine-readable JSON output
web-finder --local --json Local only, JSON - great for agents
